# LOUD DNA — THE DEEP CUTS

Reproduction HTML/CSS/JavaScript de la capture de référence.

## Utilisation
1. Ouvrir ce dossier dans Visual Studio Code.
2. Ouvrir `index.html` avec Live Server, ou double-cliquer sur ce fichier.
3. La maquette apparaît au format mobile 390 × 844 px, adaptable aux petits écrans.

## Fichiers
- `index.html` : structure des cartes artistes, récapitulatif et navigation.
- `style.css` : couleurs, dégradés, typographies, espacements et responsive.
- `script.js` : petits retours interactifs au clic.
- `assets/` : portraits fournis dans la conversation.

## Remarques
- Les photos sont les images de référence transmises pour le projet, non des photos inventées.
- Les liens HOME/LIBRARY ne naviguent pas encore vers des pages inexistantes.
- Les couleurs et dimensions peuvent être ajustées dans `style.css`.
- Importer du HTML dans Figma requiert un outil ou plugin de conversion ; ce dossier est une page web, pas un fichier .fig.
